How SummarAI works

Abstractive summarization understands the meaning of text and generates a new, shorter version. Unlike extractive systems, it is not limited to copying complete sentences from the source.

Input TextTokenizationTransformer ModelGenerated Summary

Abstractive AI

The model creates natural-language sentences based on the main ideas, rather than selecting a few source sentences.

Encoder-decoder

The encoder represents the input context and the decoder generates a coherent summary one token at a time.

Pretrained model

DistilBART has learned language patterns from large datasets, making powerful NLP accessible on a normal CPU laptop.
